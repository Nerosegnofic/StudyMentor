2- Develop an algorithm for performing the task.

4- Run the program on the computer machine.



**Types of Computational Problems:**

1- **Decision Problem:** Given a positive integer *n*, determine if *n* is prime.
2- **Counting Problem:** Given a positive integer *n*, count the number of nontrivial prime factors of *n*.
3- **Optimization Problem:** Given a graph G, find an independent set of G of maximum size.

j) **The main properties of an algorithm are:**

1- **Ordered**
Example:
Step one: Print n
Step two: Read n
This algorithm is unordered because n needs to be read before getting printed.

2- **Unambiguous**
Example:
Step one: Get n1, n2, n3
Step two: Calculate the average of n1, n2 and n3



Step three: Print the average.
This algorithm is ambiguous because we didn’t provide instructions to the computer about how to calculate the average.

**3- Executable**
Example:
Step one: Let number = -5
Step two: Print SQRT (number)
Step three: Add 1 to number
Step four: If number = 5, END
Step five: Else repeat from step 2
This algorithm is inexecutable because there is no square root for -5

**4- Terminating**
Example:
Step one: Let number = 1
Step two: Print number
Step three: Add 1 to number
Step four: Repeat from step 2
This algorithm is non-terminating because it will keep infinitely adding 1 to number.
